# Shaima Alkabani Nutrition — Website & CMS

موقع احترافي متعدد اللغات لأخصائية تغذية واحدة، مع لوحة تحكم خاصة لإدارة الموقع والمحتوى والاستفسارات. المشروع مبني على React وTypeScript وVite وSupabase، ويمكن نشره بصورة مستقلة دون الاعتماد على منصات إنشاء المواقع.

## نطاق الموقع

- صفحات عامة بالعربية (اللغة الافتراضية)، والتركية، والإنجليزية مع RTL/LTR.
- الرئيسية، من أنا، الخدمات، الباقات، المقالات، صفحة المقال، قصص النجاح، والتواصل.
- إدارة الباقات والخدمات والمقالات وآراء العملاء وقصص النجاح من لوحة الإدارة.
- محتوى وترجمات مستقلة لكل لغة في الباقات والخدمات والمقالات والآراء والقصص ونصوص صفحات الموقع والأسئلة الشائعة (يمكن إضافة الأسئلة وحذفها وتعطيل القسم لكل لغة).
- محرر مقالات يدعم تنسيق Markdown عبر أزرار سريعة للعناوين والقوائم والتنسيق.
- بيانات SEO ديناميكية، وسوم hreflang للغات، وبيانات منظمة للملف الشخصي والمقالات.
- مكتبة وسائط مبنية على Supabase Storage مع منع حذف الصورة عند اكتشاف استخدامها في محتوى الموقع.
- استقبال الاستفسارات وتغيير حالتها إلى جديدة أو مقروءة أو تم الرد أو مؤرشفة.
- روابط واتساب لكل باقة وخدمة مع رسالة تتضمن اسم العنصر، إضافة إلى إنستغرام وفيسبوك وتيك توك والهاتف والبريد والموقع.
- حماية البيانات باستخدام Supabase Auth وRLS وسياسة صلاحيات للمدير فقط.

## حدود العمل المقصودة

هذا موقع تعريفي وتسويقي لأخصائية واحدة، وليس بوابة مرضى أو منصة اشتراكات. لا توجد حسابات للعملاء، ولا تسجيل دخول للعملاء، ولا تفعيل اشتراكات تلقائي، ولا دفع إلكتروني، ولا لوحة مريض، ولا تخزين خطط غذائية شخصية. الزائر يتصفح المحتوى ثم يرسل استفساراً عبر النموذج أو يتواصل مباشرة مع الأخصائية.

لا يتضمن المشروع مؤهلات أو شهادات أو أسعاراً أو آراء أو نتائج حالات مختلقة. أضيفي المعلومات الحقيقية من لوحة الإدارة قبل النشر.

## التقنية والمتطلبات

- Node.js 20.19+ أو 22.12+.
- npm.
- مشروع Supabase.
- حساب استضافة ثابتة مثل Vercel أو Netlify.

## 1. إعداد Supabase

1. أنشئي مشروعاً جديداً في Supabase.
2. افتحي `SQL Editor`.
3. انسخي محتوى `supabase/schema.sql` كاملاً وشغّليه.
4. ينشئ السكربت الجداول والترجمات وسياسات RLS ومخزن الصور `site-assets` ودالة آمنة لاستقبال الاستفسارات مع حد مبدئي لمكافحة الإزعاج.
5. من `Authentication → Providers` اتركي تسجيل الدخول بالبريد وكلمة المرور مفعلاً للمديرة، وعطّلي التسجيل العام (Allow new users to sign up) بعد إنشاء الحساب. لا تضيفي أي رابط تسجيل للعملاء.

> إذا كان لديك مشروع Supabase قديم خاص بالنسخة السابقة، فالملف يتضمن محاولة ترحيل للجداول القديمة المتوافقة. خذي نسخة احتياطية قبل تشغيل أي ترحيل على بيانات مهمة، وراجعي سجل التنفيذ في SQL Editor.

## 2. إنشاء حساب المديرة

1. من `Authentication → Users` أنشئي مستخدماً واحداً للمديرة ببريد إلكتروني وكلمة مرور قوية.
2. انسخي `User UID`.
3. في SQL Editor نفّذي التالي بعد استبدال القيم:

```sql
insert into public.profiles (user_id, full_name, role)
values ('AUTH_USER_UUID', 'Shaima Alkabani', 'admin')
on conflict (user_id) do update
set full_name = excluded.full_name, role = 'admin';
```

4. سجّلي الدخول من `/admin/login`.

إضافة الحساب إلى `profiles` هي التي تمنحه صلاحية الإدارة. لا تعتمدي على إخفاء عناصر الواجهة كحماية؛ سياسات RLS هي التي تمنع المستخدم غير المخوّل من تعديل المحتوى.

## 3. إعداد متغيرات البيئة

انسخي `.env.example` إلى ملف باسم `.env.local`، ثم ضعي عنوان المشروع ومفتاح الواجهة العام من `Supabase → Project Settings → API`:

```env
VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=YOUR_PUBLISHABLE_OR_ANON_KEY
```

يمكن استخدام Publishable key الحديث أو anon key القديم. **لا تضعي أبداً `service_role` أو `secret key` في متغير يبدأ بـ `VITE_` أو في ملفات الواجهة.**

## 4. التشغيل المحلي

من داخل مجلد المشروع:

```bash
npm install
npm run dev
```

ثم افتحي الرابط الذي يظهر في الطرفية، وغالباً يكون `http://localhost:5173`.

للفحص والبناء:

```bash
npm run typecheck
npm run build
npm run preview
```

## 5. إعداد المحتوى قبل النشر

من لوحة الإدارة:

- **إعدادات الموقع:** الاسم والعلامة، اسم الأخصائية والمسمى، الشعار، صورة الملف الشخصي، صورة المقدمة، نبذة التعريف، المؤهلات، نصوص الصفحات، رقم واتساب، إنستغرام، الهاتف، البريد، الموقع، وروابط التواصل.
- **الباقات:** الاسم والوصف والسعر والعملة والمدة والمزايا والصورة والترتيب والظهور والتمييز. لكل باقة حقول منفصلة بالعربية والتركية والإنجليزية.
- **الخدمات:** إدارة الخدمات وترجماتها وصورها.
- **المقالات:** عنوان ورابط ومقتطف ومحتوى وتصنيف ووسوم وحقول SEO مستقلة لكل لغة، مع صورة غلاف وحالة مسودة/منشور.
- **آراء العملاء:** لا تفعّلي الظهور قبل الحصول على موافقة صاحب الرأي.
- **قصص النجاح:** لا تنشري الصور أو القصة قبل الحصول على موافقة صريحة من صاحبها.
- **الاستفسارات:** راجعي الرسائل وحدّثي الحالة، ثم تابعي مع الزائر عبر وسيلة التواصل المناسبة.
- **مكتبة الوسائط:** صور JPG وPNG وWEBP وGIF حتى 8 ميغابايت.

لإظهار باقة أو خدمة أو مقال أو رأي أو قصة، أكملي الحقول المطلوبة للغات الثلاث أولاً. يفضّل إدخال رقم واتساب بالصيغة الدولية، أرقاماً فقط مع مفتاح الدولة، مثال: `9639XXXXXXXX`.

## 6. النشر على Vercel

1. ارفعي المشروع إلى مستودع GitHub.
2. اربطي المستودع بحساب Vercel.
3. استخدمي أمر البناء `npm run build` ومجلد الإخراج `dist`.
4. أضيفي `VITE_SUPABASE_URL` و`VITE_SUPABASE_PUBLISHABLE_KEY` إلى Environment Variables في Vercel.
5. أكملي Deploy.

الملف `vercel.json` يوجه المسارات الداخلية إلى تطبيق React حتى تعمل الروابط متعددة اللغات عند فتحها مباشرة.

### النطاق وملف Sitemap

بعد اختيار النطاق النهائي، استبدلي `YOUR_DOMAIN` في `public/sitemap.xml` بنطاق الموقع الفعلي (من دون `/` في النهاية)، ثم أعيدي النشر وأضيفي رابط Sitemap إلى Google Search Console. راجعي أيضاً `robots.txt` بعد ربط النطاق.

## 7. الأمان والخصوصية

- الزوار يستطيعون قراءة المحتوى المنشور فقط.
- الزوار لا يستطيعون قراءة جدول الاستفسارات أو إدخال صفوف فيه مباشرة؛ يرسل النموذج البيانات عبر RPC محدودة المعدل.
- لا توجد جداول لحسابات العملاء أو الاشتراكات أو الدفع أو الخطط الغذائية الشخصية.
- رفع الصور وتعديل المحتوى محصوران بالمديرة من خلال RLS.
- لا تضيفي معلومات صحية حساسة إلى نموذج التواصل؛ الغرض منه استقبال استفسار أولي فقط.
- قصص النجاح والصور وآراء العملاء تحتاج موافقة صريحة قبل النشر.
- أضيفي سياسة خصوصية مناسبة للقانون المحلي قبل الإطلاق التجاري.

## 8. ملاحظات التحقق

لم يكتمل تثبيت حزم npm في بيئة إعداد هذه الحزمة بسبب تعذّر الاتصال بسجل npm/انتهاء مهلة الشبكة. لذلك لا أصف البناء أو ربط Supabase الفعلي أو اختبار RLS بأنه تم. بعد فك الضغط وربط المشروع، نفّذي أوامر الفحص في القسم 4، ثم اختبري تسجيل دخول المديرة، رفع الصور، إنشاء المحتوى وترجماته، إرسال استفسار تجريبي، أرشفته، وروابط واتساب على مشروع Supabase فعلي قبل النشر.
