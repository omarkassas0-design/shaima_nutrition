# Base44 dependency report

## Production runtime replacement

The active Vite package manifest and build configuration no longer install or configure `@base44/sdk` or `@base44/vite-plugin`. The browser uses `src/api/supabaseClient.js` and `src/api/appClient.js`. App functions run behind `/api/functions/:name` in `worker/src/index.js`, and entity compatibility methods use the Supabase-backed adapter in `worker/src/compat/platform-sdk.js`. Auth, storage, file signing, email, extraction, Google Drive, PWA, and scheduled workflows have replacement paths or explicit missing-provider errors.

The old function names and JSON contracts are kept through the handler map in `worker/src/handler-map.js`; local copies of the shared modules and function handlers are under `worker/src/legacy/`. This adapter provides the former handler API shape, but it is local project code and imports no Base44 SDK at runtime.

## Remaining references and their purpose

- `base44/` contains the original backend/configuration source retained as an audit archive. It is not imported by Vite, Wrangler, or the active Worker handler map. Do not deploy this directory as an API.
- `migration/source-entities/`, `migration/source-workflows/`, and `migration/source-config/` preserve source definitions needed for schema generation and migration review.
- `scripts/import-base44-export.mjs`, `scripts/build-migration-inventory.mjs`, and `docs/` name Base44 to identify the source platform and export format.
- `migrateLegacyFiles` and an allowlisted `base44.app` host are migration-only; they exist to transfer existing private file contents while the source host remains available. The path should be removed after verified file migration.
- The old marketing email under `base44/emails/` is retained with its original URLs for reference; the active Worker email template under `worker/src/templates/` uses local assets.

## Checks

The full-repository search should be repeated before each release. A `base44` match under the archive or migration docs is expected; a match in active package dependencies, Vite initialization, Worker network routing, frontend Auth, or ordinary database access is not. The package lockfile is regenerated by `npm install` during this task. No production Base44 account was available to verify shutdown of the legacy service or completion of private-file transfer.
